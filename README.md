# Visual Scripting 2D

Our draft:

A 2D, pixel-art, top-down web game that implements a node-based visual scripting system integrated into the gameplay itself. Nodes appear as physical objects within the game world, that can be interacted with (e.g, placed down, picked up, collided with?). Wires can be used to connect nodes, and are a part of the game world.
Their programming journey could be complemented by a basic storyline, helping make the game more lively and fun.
At first, limited actions are available to the player, guiding them to learn simple programming concepts. As the player progresses, they unlock new nodes that can be used more creatively and allow multiple solutions to problems.
The player has a questbook, that helps them through the game and tracks their progress. As well as this, an XP bar is present that gives a sense of accomplishment and tracks their learning progress.
